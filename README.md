# Golden Palace — сайт банкетного комплекса

Одностраничный сайт банкетного комплекса Golden Palace (Москва, 3-я улица Ямского Поля, 15).
Информация и фото залов взяты со страницы площадки на wedwed.ru — своего сайта у комплекса нет.

## Структура

```
index.html               — вся страница
assets/css/style.css     — стили
assets/js/main.js        — анимации, галерея, лайтбокс, калькулятор, форма заявки
assets/img/halls/        — реальные фото залов (webp): zolotoy-, sfera-, antichny-, kino-, vyezd-
assets/img/gen/          — сюда класть сгенерированные картинки (см. PROMPTS.md)
assets/video/hero.mp4    — видео для главного экрана (необязательно)
PROMPTS.md               — промпты для генерации картинок и видео
```

## Блоки страницы

Главный экран · форматы (бегущая строка) · о комплексе · 4 зала с ценами · выездная регистрация ·
подбор зала и бюджета · форматы событий · как мы работаем · банкетное меню · подарок за бронирование ·
галерея · вопросы · форма заявки · контакты и карта.

## Как поменять

- **Цены и вместимость** — в `index.html` (карточки залов, вопросы) и в `CALC_HALLS` в `assets/js/main.js` (калькулятор).
- **Телефон для заявок** — переменная `WHATSAPP` в `assets/js/main.js` и ссылки `tel:` в `index.html`.
- **Фото** — заменить файл в `assets/img/halls/` с тем же именем. Количество фото по залам — в `HALLS` в `main.js`.
- **Сгенерированные картинки** подхватываются автоматически, если положить их по путям из `PROMPTS.md`.

## Форма заявки

Бэкенда нет: по кнопке открывается WhatsApp банкетного менеджера с заполненным сообщением
(дата, гости, зал, формат, имя, телефон).

## Локальный запуск

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000.

## Публикация

Сайт публикуется через Vercel: Add New → Project → импортировать репозиторий `golden-palace`,
Framework Preset — Other, сборка не нужна (статические файлы из корня). После этого каждый push в `main` выкладывается автоматически.
